# Vektra: сайт на Next.js і TypeScript

## Як запустити

**Windows:** двічі клацніть `start.bat`. Перший запуск встановить залежності й збере сайт, це займе кілька хвилин. Потім сайт відкриється за адресою http://localhost:3000.

**Будь-яка система:** потрібен Node.js 20.9 або новіший.

```bash
npm install
npm run build
npm start
```

Для роботи з кодом: `npm run dev`.

## Статистика та адмінка

Для статистики й редагування сторінок потрібна PostgreSQL-база. Додайте до `.env.local` значення `DATABASE_URL`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` та `ANALYTICS_HASH_SECRET` з `.env.example`. Секрети генеруйте окремо та не додавайте до Git.

Перед першим запуском додайте змінні оточення та застосуйте міграції: `npm run db:migrate`. Prisma Client генерується командами `npm run dev`, `npm run db:generate`, `npm run build` і `npm run typecheck`.

Адмінка доступна за адресою `/admin` і захищена паролем із `ADMIN_PASSWORD`. Редактор `/admin/services` дає змогу вибрати одну з шести послуг, налаштувати власний порядок і заголовки секцій, обрати ілюстрацію з прев’ю та змінити контент сторінки. Під час першого відкриття шаблони автоматично додаються до бази; BrandingPage переноситься з поточними текстами.

Адмінка доступна за адресою `/admin` і захищена паролем із `ADMIN_PASSWORD`. Вона показує перегляди, приблизну кількість унікальних відвідувачів, країни, пристрої, браузери, сторінки та останні 50 переглядів. Записи включають IP; записи старші за 30 днів видаляються під час збору нових подій або відкриття адмінки. Аналітика фіксує перегляд після завантаження сторінки та під час переходів усередині сайту; сирий User-Agent не зберігається. Країна визначається з Vercel/Cloudflare заголовка. Якщо сайт розміщений за іншою інфраструктурою, країна залишиться невідомою, доки не буде додано її довірений заголовок.

## Де що лежить

- `lib/content.ts`: усі тексти, послуги, кейси, відгуки, контакти.
- `public/illustrations`: ілюстрації. `lib/illustrations.ts`: їхні розміри й характер руху.
- `public/images`: фото проєктів і логотипи клієнтів.
- `lib/particles.ts`: анімація ілюстрацій на WebGL.
- `components/Motion.tsx`: анімації текстів і скролу, переходи між сторінками.
- `components/RequestModal.tsx`: попап заявки. Відкривається з будь-якої кнопки через `RequestButton`.
- `styles/system.css`: кольори та основа. `styles/sections.css`: секції. `styles/responsive.css`: планшет і телефон.

## Заміна ілюстрацій на оригінали з Figma

Файли зараз вирізані зі скриншотів макета. Експортуйте оригінали у PNG (бажано 2x), назвіть так само й покладіть у `public/illustrations`:
`hero`, `flower`, `lattice`, `knot`, `wave`, `sphere`, `infinity`, `vortex`, `web`.
Потім оновіть `w` і `h` у `lib/illustrations.ts`. Форма, частинки й рух перебудуються самі. Підходить чорний або прозорий фон.

Фото проєктів так само замінюються в `public/images`: `pumplab.jpg`, `clave.jpg`, `softh-cto.jpg`.

## Куди приходять заявки

Форми надсилають заявки на `/api/requests`, який передає їх у Telegram. Для цього задайте `TELEGRAM_CHAT_ID` і `TELEGRAM_BOT_TOKEN` у `.env.local`. Якщо `NEXT_PUBLIC_REQUEST_ENDPOINT` задано, заявки надсилатимуться на цей зовнішній обробник замість вбудованого маршруту.

## Адаптив

| Ширина | Макет | Масштаб |
|---|---|---|
| від 1200 px | десктоп, 4 колонки | 1rem = ширина / 144, до 1920 px |
| 768–1199 px | планшет, 2 колонки | 1rem = ширина / 83.4, до 11.5 px |
| до 767 px | телефон, 1 колонка | 1rem = ширина / 39 |

Якщо в системі ввімкнено зменшення руху, анімації вимикаються, а ілюстрації показуються статичними.
